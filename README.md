# Professional Portfolio - Shiva Kumar Gunda

A modern, dark-themed, and responsive portfolio website built with HTML, CSS, and JavaScript.

## 🚀 Features
- **Dark Premium Design**: Charcoal and Cyan color palette.
- **Dynamic Hero Section**: With glassmorphism effects and smooth transitions.
- **Scroll Reveal Animations**: Using ScrollReveal.js for entry effects.
- **Responsive Layout**: Optimized for mobile, tablet, and desktop.
- **Interactive Project Cards**: Hover effects with GitHub links.
- **Education Timeline**: Visual journey of academic achievements.
- **Skills Grid**: Organized categorizations of technical expertise.

## 🛠️ Setup Instructions
1. **Profile Photo**: 
   - Save your photo as `profile.jpg` in this directory.
   - The website is currently configured to use this file. If it's missing, it falls back to a professional avatar.
2. **Resume**:
   - Save your PDF resume as `resume.pdf` in this directory.
   - Update the "Download Resume" link in `index.html` if the filename is different.
3. **Contact Form**:
   - The form currently shows an alert. To make it functional, consider using [Formspree](https://formspree.io/) or a similar service.

## 📂 File Structure
- `index.html`: Main structure and content.
- `style.css`: All styling, including animations and responsive queries.
- `script.js`: Interactive elements, scrolling logic, and animations.
- `profile.jpg`: (User to provide) Your professional headshot.
- `resume.pdf`: (User to provide) Your downloadable resume.
